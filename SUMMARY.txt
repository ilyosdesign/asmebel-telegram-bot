QADAM 1: Render.com'da Deploy Qilish
   → https://render.com ga kirish
   → "New Web Service" yaratish
   → GitHub repository'ni ulash (ilyosdesign/asmebel-telegram-bot)
   → Build: pip install -r requirements.txt
   → Start: python bot.py

QADAM 2: Environment Variables Qo'yish
✓ TELEGRAM_TOKEN = YOUR_TOKEN (from .env)
   ✓ GEMINI_API_KEY = YOUR_KEY (from .env)
   ✓ ADMIN_ID = YOUR_ID (from .env)
   ✓ ADMIN_USERNAME = YOUR_USERNAME (from .env)
   ✓ PORT = 10000 (Render uchun)
   ✓ WEBAPP_URL = https://your-app.render.com

QADAM 3: Telegram Webhook O'rnatish
   curl -X POST https://api.telegram.org/bot{TOKEN}/setWebhook \
     -H'Content-Type: application/json' \
     -d '{"url":"https://your-app.render.com/webhook"}'

QADAM 4: Bot Test Qilish
   → Telegram'da bot'ga /start yuborish
   → /katalog - Mebel ko'rish
   → /admin - Admin panel
   → /app - Web interfeys
